# v12.0.0 Geçiş Rehberi

1. Çalışan proje klasörünün tam yedeğini alın.
2. `KUR_V12_0_0_PRODUCTION_FINAL.bat` dosyasını çalıştırın.
3. Çalışan `FirsatAI-v4` klasörünü seçin.
4. Final raporundaki `DURUM` değerini kontrol edin.
5. Canlı dağıtım öncesinde `.env.v11_3_1.production.example` şablonundan production ortamını oluşturun.

Geri dönüş için kurulum çıktısında yazan `backups/v12_0_0_final_*` klasöründeki dosyaları geri kopyalayın. Veritabanı bu sürüm tarafından değiştirilmez.
